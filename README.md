# Apex Abyss

Roblox underwater eat-and-grow game: start small, eat your way up to apex predator,
bank your Haul at your den. Design: [`docs/GDD.md`](docs/GDD.md). Project notes and
decisions: [`CLAUDE.md`](CLAUDE.md).

## Running it

```
rokit install
rojo serve
```

Then connect the Rojo plugin in Roblox Studio and press Play.
