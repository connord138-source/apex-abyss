## Setup problems

1. `git pull origin claude/core-systems` was already up to date at `f47957d`.
2. **Toolchain:**
   - StyLua 2.0.2 and selene 0.28.0 came from rokit.
   - luau-lsp isn't installed on this PC, so I didn't run `tools/verify.sh`. Studio's Script Analysis did the type check instead.
3. **StyLua and line endings:** this clone checks files out with CRLF (`core.autocrlf=true`), so a plain `stylua --check` reports every file. I format with `stylua --line-endings Windows src --glob "!**/Packages/**"`, which passes and leaves git's diff clean.
4. **Script Analysis:**
   - 0 errors throughout.
   - Warnings went 80 → 81. The new one is a "Value of type 'Camera?' could be nil" on my new line in `CameraController` (line 218). Lines 123, 229, 231, 269 and 277 of that file already carry the same warning.
   - selene: the same 3 warnings before and after my changes.
5. **Device Simulator quirk:** typing into Studio's command bar flips `UserInputService.KeyboardEnabled` on until the next touch on the game view. Meanwhile `Input.isTouch()` reads false, which is why the SHOP button appeared only after a tap. A real phone doesn't do this.
6. **Mouse look in Play:** with the cursor locked, Roblox puts it back at the view's centre (606, 322) every frame, so each move of mine counts from there. Aiming by moving to (606 + Δx, 322 + Δy) gives about 0.24° per pixel.

## Fix tests

### 1. Controller sticks: FIXED

The logger read the pad state (L, R), speed v and the fish's and camera's yaw every 0.5 s (`F1-01`–`F1-03`).

- **Left stick up, 1.5 s:** speed went 14.4 → 18.5 → 19.6. On release (stick 0) it went **8.6 → 3.7 → 1.6 → 0.7 → 0.2**, and the heading held at −165°: the fish coasted to a stop facing forward. On the old build it held about 20 indefinitely.

- **Right stick right (L):** the camera stopped at −39° on release.
- **Right stick left (J):** the camera stopped at 123° on release.

### Found in the regression: camera flash through a den roof: FIXED

- **The bug:** in Den 1 under the ceiling, looking fully down, one reading had the camera at y 37.1, straight above the fish, with the ceiling at y 30 (`F6-01`).

  - Back-to-wall fade: 0.80 at 0.2–0.5 studs, then **0.00** once you swim away (`F6-04`).
  - Swimming out of the den: 6.7–8.6 studs, no jumps.
