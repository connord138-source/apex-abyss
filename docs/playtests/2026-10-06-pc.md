**Blocker 1: WASD never moves the fish.** Roblox's default `PlayerModule` is never inserted. During Play, `PlayerScripts` holds only `Client` and `RbxCharacterSounds`, and `StarterPlayerScripts` holds the same two. `Input.luau:44` waits on `PlayerModule` forever, so `controls` stays nil and `Input.moveVector()` always returns zero. A check from the command bar while W was held printed:

```
KEYW true PM nil TB nil MB Enum.MouseBehavior.LockCenter LAST Enum.UserInputType.Keyboard
```

The game sees the key; it just has no move vector. Everything that reads keys through `UserInputService` directly still works:

- Space / C (up/down)
- Shift / Q (Dash)
- click (bite + lunge)

The only difference from Hatch & Snatch's setup I could find is `Players.CharacterAutoLoads = false` (`FishService.luau:164`), but I haven't confirmed that's the cause. Suggested fix: make `Input.moveVector()` build the vector itself from the `held` table (WASD/arrows) and `Thumbstick1`, and treat the PlayerModule as optional.

**Blocker 2: stall prompts don't work.** Details are under test 7.

### 2. Swimming: FAIL

- **WASD: no movement** (see blocker 1). Every move I thought W made in my first session was actually a click-lunge.
- **Space / C:** work. Holding Space for 2 s raised the fish 12 studs, to the den ceiling.
- **Click (bite):** lunges about 16–26 studs along the current heading.
- **Shift dash:** fires (its input path doesn't use the PlayerModule), but I couldn't separate its effect from the lunges.
- **Steering:** the fish's heading never turns horizontally, because heading only follows velocity and only vertical input exists. So the fish can only travel along its spawn line (Den 1 → plaza center → Den 7) or up and down.
- **Mouse look:** works, at about 0.24° per pixel.
- **Camera problems:**
  - It clips through rock. With the fish against the Den 7 ceiling (y≈29), the camera sat at y≈42, above the ceiling, looking down through it (`04-camera-above-den-ceiling.jpg`).

- **Smoothness:** I can't judge frame-to-frame smoothness from screenshots. I saw no rubber-banding or teleports.

### 7. Vendors: FAIL

The plaza has four stalls: Den Mason, Shade Dyer, Tidecharm Trader, Fin & Gill Outfitter. **No prompt ever appeared, and E never opened a shop.**

1. With the fish resting 17.3 studs from the Fin & Gill Outfitter counter (`ShopPrompt` reach is 18), no prompt showed. Pressing E did nothing, and `PromptShown` never fired (`17-outfitter-no-prompt.jpg`). A command-bar check printed:

   ```
   PPS true MAXP 16 PRIM HumanoidRootPart HROOT HumanoidRootPart HP 100 PROMPT true 18 Workspace.World.Hub.Vendors.Outfitter.Counter DIST 17.2558650970459
   ```

2. As a diagnostic, I raised every prompt's reach to 60, only in that Play session on the client. It still showed nothing while the fish sat at that spot. A simulated `InputHoldBegin/InputHoldEnd` on the Outfitter prompt didn't fire `PromptTriggered` either.
3. Once the fish moved to the plaza center (about 33 studs from every counter), the 60-reach prompts started flickering: "SHOWN Tidecharm Trader" / "HIDDEN Tidecharm Trader", then the same for Shade Dyer, every 0.1–2 s.

The 18-stud prompt also can't be reached without steering. Suggested fix: drop the dependence on ProximityPrompt behaving with this custom character. Have `MenuController` check the distance to `WorldService.vendorPosition` itself and show its own "E · Shop" hint.
