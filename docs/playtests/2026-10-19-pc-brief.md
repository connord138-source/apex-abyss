## 1. Sync

1. Merge `origin/claude/world` into `claude/core-systems`.
2. Run `rokit install`, then `rojo serve`, and connect the plugin.
3. Format with `stylua --line-endings Windows src --glob "!**/Packages/**"`.
4. Play once. The Output should show no errors. Copy these start lines:
   - `[ForageService] … prey schools lifted over the ground (X ms)`. Expect about 2.5× the old time.
   - `[WorldService] Vents: …`
   - `[Ruins] …`

## 2. Imports and one upload (in `ApexAbyss.rbxl`; screen everything first, and never upload a normal map)
