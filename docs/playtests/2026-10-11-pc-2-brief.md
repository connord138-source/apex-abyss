## 1. Merge, sync and import

1. git fetch origin claude/world, then git merge origin/claude/world.
2. stylua --line-endings Windows src --glob "!**/Packages/**"
3. python tools/fetch_assets.py. It downloads `vendors_glb` v2 (sha256 917bf7b7…) and `shade_skins` v7 (sha256 SHA7…).
4. **Screen first**, with the classifier:
   - `python tools/shades/screen_shades.py assets/glb/props/KeeperOutfitter.glb assets/glb/props/KeeperMason.glb assets/glb/props/KeeperCharms.glb assets/glb/props/KeeperDyer.glb assets/glb/props/KeeperTrophies.glb`: expect "5 screened, none flagged" and exit 0.
   - `python tools/shades/screen_shades.py assets/shades/glb/<Fish>_Shades.glb --base <your fish textures>` for all six fish (Nibbler, Cuda, Puffer, MorayEel, ReefShark, Angler), as you did last round: expect none flagged and exit 0 for each.
5. In `ApexAbyss.rbxl`, edit mode, File → Import 3D **one at a time, a few minutes apart**:
   - The six `assets/shades/glb/<Fish>_Shades.glb`, one at a time; then run `tools/studio/organize_shades.luau` (expect 27 skins for each of 6 fish, 162).
   - The five `assets/glb/props/Keeper<Id>.glb`: KeeperOutfitter, KeeperMason, KeeperCharms, KeeperDyer, KeeperTrophies. If one comes in named "Scene", rename it to its file name in the Import Preview first. Then run `tools/studio/organize_imports.luau` (expect `ReplicatedStorage.WorldProps.KeeperOutfitter` … `KeeperTrophies`).
   - If Roblox rejects or moderates any image, stop and report it. Don't retry, and never upload from another account.
6. **Upload sound pack v2:** Asset Manager → Import → `assets/audio/apex_sfx.ogg` → Import Queue → Start Import (accept the rights-and-fee dialog as last time). Right-click its row → Copy AssetId, and paste it into `src/shared/Config/Sounds.luau` as `id = <that id>`. Leave `legacy` as it is. If moderation rejects it, stop and report; the game keeps the v1 pack meanwhile.
7. Save `ApexAbyss.rbxl`.
8. rojo serve on port 34873, connect, Play Solo. Expect "Server started" and "Client ready", no errors. Note how long the server takes to build the world (the rounded rocks add about 2,300 Terrain fills).
