## 1. Sync

1. Merge `origin/claude/world` into `claude/core-systems`.
2. Run `rokit install`, then `rojo serve`, and connect the plugin.
3. Format with `stylua --line-endings Windows src --glob "!**/Packages/**"`.
4. Play once. The Output should show no errors. Copy the start lines of `[ForageService]` and `[ShellService]` (they're checked in SP1).

## 2. Skins v12 patch (in the same `ApexAbyss.rbxl`, after v11)

1. Run `python tools/fetch_assets.py`. It should print `fetched shade_patch_v12: 6 file(s) -> assets/shades/patch12 (sha256 d94abb99)`.
2. Screen each pack with the classifier on (nothing is uploaded by this). Each must exit 0; if one doesn't, stop and report its output:

   ```
   python tools/shades/screen_shades.py assets/shades/patch12/Nibbler_ShadesPatch.glb --quiet
   python tools/shades/screen_shades.py assets/shades/patch12/Puffer_ShadesPatch.glb --quiet
   python tools/shades/screen_shades.py assets/shades/patch12/MorayEel_ShadesPatch.glb --quiet
   python tools/shades/screen_shades.py assets/shades/patch12/Angler_ShadesPatch.glb --quiet
   python tools/shades/screen_shades.py assets/shades/patch12/Cuda_ShadesPatch.glb --quiet
   python tools/shades/screen_shades.py assets/shades/patch12/ReefShark_ShadesPatch.glb --quiet
   ```

3. File → Import 3D the six `assets/shades/patch12/<Fish>_ShadesPatch.glb` files **one at a time, a few minutes apart** for moderation (images: Nibbler 48, Puffer 46, MorayEel 49, Angler 63, Cuda 11, ReefShark 11). Don't re-import anything else.
4. Paste `tools/studio/organize_shades.luau` into the Command Bar and Run. It files 116 skins and keeps every other skin.
5. Save (Ctrl+S).
